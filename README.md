# Gyros Hero – Frontend

This is the React.js frontend for Gyros Hero restaurant. It displays a dynamic menu fetched from Square API, provides an engaging user experience, and redirects customers to the Square checkout for online ordering.

## Features

- Fully responsive React UI
- Square API integration to fetch live menu
- SEO-optimized with metadata and loading states
- Contact form and about page
- Custom domain deployment via Render

## Tech Stack

- React.js (with functional components)
- React Router
- Axios
- Square API
- Render (deployment)

## Run Locally

```bash
npm install
npm start
```
